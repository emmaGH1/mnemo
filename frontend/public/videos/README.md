# Videos

Drop demo recordings here to replace the placeholder panels in the video
section:

| File                | Card          |
| ------------------- | ------------- |
| `watch.mp4`         | 01 / Watch    |
| `check.mp4`         | 02 / Check    |
| `agent.mp4`         | 03 / Agent    |

Optional posters: `watch_poster.png`, `check_poster.png`,
`agent_poster.png`.

After dropping a file in, set `ready: true` for that entry in the `videos`
array in `src/components/VideoCards.tsx`. Play/pause on viewport visibility
(≥40%) is already wired.
